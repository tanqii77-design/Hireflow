# HireFlow Roadmap

## v1 — MVP ✅ (Completed)

- ✅ Job management (CRUD + open/closed status)
- ✅ Candidate management (CRUD + 6-stage status flow)
- ✅ Multi-round interview scheduling (video/phone/onsite)
- ✅ Structured feedback (rating + strengths + concerns)
- ✅ AI interview assessment (upload TXT interview notes → AI draft feedback)
- ✅ AI job matching (resume × JD → scores + recommendations)
- ✅ AI smart onboarding (upload PDF → auto-extract info + batch match)
- ✅ Dashboard with pending feedback alerts
- ✅ Status workflow with business rules (auto-transition + locked states)
- ✅ PDF resume upload (text extraction + OCR for scanned documents)
- ✅ Neumorphic UI design system
- ✅ SQLite (local) + Turso (production) dual database support
- ✅ Demo data seed script
- ✅ Vercel deployment ready

## v2 — Planned

### Team Collaboration & Roles
- Multi-user support with role-based access (Intern / HR / Manager)
- Team dashboards showing shared pipelines
- Interviewer assignment notifications

### Data Ownership & Audit
- Per-user data isolation
- Audit logs for all status changes and data modifications
- Export/backup functionality

### AI Enhancements
- OCR accuracy improvements for complex scanned PDFs
- Voice-to-text interview note transcription
- AI-generated interview questions based on JD
- Bulk candidate matching

### Workflow & Integrations
- Calendar integration (Google Calendar / Outlook)
- Email notifications for interview scheduling
- Slack/Teams notifications for pending feedback
- API for external system integration

### Polish
- Dark mode
- Keyboard shortcuts
- Bulk candidate import (CSV)
- Custom feedback templates
